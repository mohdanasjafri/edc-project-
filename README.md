# VentureVerse 2026 — EDC JSSUN Technical Task

A beginner-friendly, responsive event landing page for the fictional event brief provided in the EDC JSSUN Recruitment 2026 task.

## Files
- `index.html` — page structure and event content
- `style.css` — visual design, layout, and responsive styles
- `script.js` — agenda rendering, mobile navigation, and demo registration interaction

## How to run
1. Extract the ZIP file.
2. Open the `ventureverse_edc_task` folder.
3. Double-click `index.html` to open it in a browser.
4. For a smoother development workflow, open the folder in VS Code and use the Live Server extension (optional).

## Features
- Required sections: header/navigation, hero, about/highlights, schedule, fictional speakers, and footer.
- Responsive layout for desktop and mobile.
- Schedule generated from a JavaScript array.
- Mobile navigation toggle.
- Demo registration form with client-side feedback only; no data is sent or stored.
